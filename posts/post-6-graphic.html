The pipeline

How Graph RAG Agent Mining Works

7 small, readable Python modules — no graph-RAG framework in between.

1

Source manuals — data/raw/

Four synthetic maintenance manuals, one per mining asset type.

▼
2

Extraction — src/extraction.py

An LLM extracts structured triples using only 4 allowed relations.

▼
3

Graph construction — src/graph_builder.py

Triples become one directed graph (NetworkX) — no external DB.

▼
4

Entity linking & specificity check — src/graph_query.py

Maps the question to a real node; asks for detail if it's ambiguous.

▼
5

Deterministic traversal — src/graph_query.py

A plain algorithm — not the LLM — walks up to 3 hops.

▼
6

Grounded answer — src/answer_builder.py

The LLM answers only from the traced path, citing the source.

▼
7

Interface — app.py (Streamlit)

Chat UI with a live animation tracing the graph nodes visited.

Open source, synthetic data, zero graph-RAG frameworks.
